# v0.2 范围与非目标

## 已完成

- WeKnora GraphData 适配与证据规范化
- 保守实体归一
- Assertion/Evidence
- 图模式统计与候选本体生成
- Domain/Range 置信度与 Review Queue
- 本体/实体图确定性校验
- 候选/批准版本注册表
- WeKnora ExtractConfig 编译
- Semantic Catalog
- Fast Retrieval Planner
- Deterministic Knowledge Arbiter
- 并行 Context Service + Context Pack
- WeKnora Wiki/RAG HTTP Adapter + Chunk Evidence API
- MCP stdio server
- Ontology / Retrieval 两个 Skill
- LLM 语义归纳、复杂规划、冲突槽位判断提示词

## v0.2 非目标

- 不把 Semantica 包嵌入运行时
- 不修改 WeKnora 内部 GraphRAG / Wiki 源码
- 不实现完整 Neo4j Governed Graph 持久化
- 不自动批准类型合并、层级、强约束
- 不让 LLM 决定权威来源或冲突赢家
- 不承诺完整 OWL/SHACL 兼容

## v0.3 建议

优先开发 Governed Graph Store + Incremental Sync + Review API，然后再接真实 OpenClaw Runtime 和业务 MCP。
